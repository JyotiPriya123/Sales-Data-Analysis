# Sales Data Analysis Project

## Project Overview
This project analyzes sales data to identify business
trends, revenue patterns, and product performance.

## Objectives
- Analyze total sales and revenue.
- Identify top-performing products.
- Understand monthly sales trends.
- Generate business insights from data.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Analysis
- Total Revenue
- Monthly Sales Trends
- Top-Selling Products
- Product Performance
