# 📊 Sales Data Analysis Project

## 📌 Project Overview
This project analyzes sales data using Python to
understand product performance and revenue trends.

## 🎯 Project Objectives
- Calculate total sales revenue.
- Analyze units sold for each product.
- Identify the highest revenue-generating product.
- Visualize product performance using charts.

## 🛠️ Tools & Technologies
- Python 3.9
- Matplotlib
- Python Lists and Loops
- Data Visualization

## 📈 Key Results
- Total Revenue: ₹11,22,000
- Total Units Sold: 202
- Top Revenue-Generating Product: Laptop
- Laptop Revenue: ₹5,00,000

## 📊 Visualizations
The project includes:
1. Product-wise Revenue Chart
2. Units Sold by Product Chart

## 💡 Business Insights
- Laptops generate the highest revenue.
- Mouse has the highest sales volume.
- Product revenue varies based on price and units sold.
